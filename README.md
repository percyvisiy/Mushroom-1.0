# Mushroom-1.0
2D game

Mushroom-1.0 is a simple game I built while teaching myself game development with Godot and GDScript. It was an opportunity to experiment with game mechanics, player movement, and debugging while learning by building.

## What I Learned
- Implementing player movement.
- Writing and debugging GDScript.
- Turning ideas into a playable game.

## Built With
- Godot Engine
- GDScript

## About
This project marks one of my early steps into game development. It reflects my curiosity, persistence, and passion for creating interactive experiences.
